# Signal Spire

Original Roblox horror-obby prototype. Download and extract [`Signal-Spire-Project.zip`](Signal-Spire-Project.zip), then open `Signal-Spire/SignalSpire.rbxlx` in Roblox Studio. The archive includes the editable Luau source, deterministic place builder, competitor notes, and setup guide.

The project is a prototype, not yet Studio-playtested or ready to claim as a finished/revenue-ready game. See the included README for controls, known limitations, and next testing milestones.
